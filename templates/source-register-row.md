# ── Source Register 行模板 ────────────────────────────────────────────────────
#
# 本 skill **不擅自编号**（`sourceRegisterEntries[].id` 允许为 null）：
# 目标库的 `S##` 由该库维护者分配。gen_notes.py 只产出「待插入的行」，
# 并把当前表头与最后一行的编号一起打印出来，供人工决定下一个 `S##`。
#
# 三个库的表头**实测不同**，不要照抄一个库去改另一个库：
#
#   细胞生物学和组织学  09 参考资料/Source Register.md
#     | ID | 类型 | 原始文件 / 来源 | 日期 | 状态 | 备注 |
#
#   心理与精神健康      09 参考资料/Source Register.md
#     | ID | 类型 Type | 标题 / 文件名 | 日期 | 状态 Status | 备注 |
#
#   有机化学            09 参考资料/Source Register.md
#     （需在运行 gen_notes.py 时读表头确认；本 skill 不假设）
#
# 列语义（三库共通）：
#   ① ID            `S##`，由目标库分配；**本 skill 留空或占位**
#   ② 类型          「课程课件 PDF」「课程回放页」「课堂转写」「课堂截图」…
#   ③ 原始文件/来源  文件名 + 定位（页码/时间范围）；媒体未归档时**只写文件名，不建失效链接**
#   ④ 日期          **材料接收日期**，与课堂日期区分（`sourceRegisterEntries[].date`）
#   ⑤ 状态          如「已保存；69 页逐页核对；已整理」「已转录；原始媒体未归档」
#   ⑥ 备注          页码异常、纯图页、文本顺序错乱、PDF 是选页、未归档材料等都要写
#
# 一行（细胞库表头）：
| {{id}} | {{type}} | {{source}} | {{date}} | {{status}} | {{note}} |
#
# 一行（心理库表头）：
| {{id}} | {{type}} | {{title_or_file}} | {{date}} | {{status}} | {{note}} |
#
# ── 硬规则 ────────────────────────────────────────────────────────────────────
# 1. **不给已删除的媒体建 wikilink**：原始视频/音轨已清理时，只登记来源、日期、
#    节次、原始文件名与「原始媒体未归档」状态，**不建立指向不存在文件的链接**。
# 2. **不写本机绝对路径、签名 URL、cookie、token**。
# 3. **一节课拆成两段时分别登记**（一行一节），对应真实的 `source.sessions[]`；
#    这**不影响**它们合成同一篇 L 笔记。
# 4. 必须登记、不能静默的事实：
#      - 页脚异常（`pageNoStatus` = anomalous / mismatch / missing）
#        ⚠️ 页脚重复**不算异常**——页脚是小节编号（`pageNoScope: section`），
#        同一小节多页共享同一编号是正常的，不要登记成问题。
#      - 纯图页（`isPureImagePage`）、文本顺序错乱（`textExtractionIssue`）
#      - PDF 是选页（`pdf.isSelection`）
#      - 未归档材料（`unarchivedMaterials[]`）
#      - 嵌入媒体未导出（如 L08 p13 的 video 页）
#      - 平台课件轨是**屏幕快照轨**（含教师桌面 / PowerPoint 编辑窗口），不是干净原图
# 5. 派生页图与 OCR **标明其来源**，不当成独立证据。
